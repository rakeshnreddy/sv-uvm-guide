  ## Local Variables in Sequences
  *IEEE 1800-2023, Clause 16.10: Local variables*

  Local variables let an assertion remember data from an earlier point of an attempt and compare it later in the same attempt.

  <InteractiveCode>
  ```systemverilog
  // data must still hold the requested value when ack arrives one cycle later
  property p_data_held_until_ack;
    logic [7:0] v;                         // one private copy per attempt
    @(posedge clk) disable iff (!rst_n)
      (req, v = data) |=> (ack && data == v);
  endproperty

  a_data_held: assert property (p_data_held_until_ack)
    else $error("data changed between request and ack");
  ```
  </InteractiveCode>

  The antecedent `(req, v = data)` matches only on edges where `req` is high, and stores the sampled `data` into `v` for that attempt. `|=>` then checks `ack` and the stored value one edge later. Without the implication, a sequence asserted on its own, such as `(req, v = data) ##1 (ack && data == v)`, must match from every attempt's start edge, so it **fails on every clock where `req` is low** (§16.12.2). Use the trace lab in [I-SV-4A](/curriculum/T2_Intermediate/I-SV-4A_SVA_Fundamentals/index) to see that failure pattern with a bare `req ##2 ack`.

  ### Why Use Local Variables?

  - Each evaluation attempt gets its own copy, so overlapping transactions do not overwrite each other's data (§16.10).
  - They check relationships across time without extra modeling code in the testbench or design.

  ### Advanced Tips

  - Local variables have no `static` or `automatic` qualifier. The declaration takes only a data type (the `assertion_variable_declaration` grammar, §16.10 and A.2.10), and each attempt always gets its own private copy. To share state across attempts, use a module-level variable written by procedural code, or modeling code in a checker.
  - Local variables cannot be passed to sampled-value functions such as `$past` (§16.9.3), and they cannot appear in a `disable iff` condition (§16.12).
  - Pair local variables with `default clocking` and `default disable iff` to keep long properties readable.
