  ## Parameterized (Generic) Classes
  *IEEE 1800-2023, §8.25 Parameterized classes*

  Parameterized classes let one definition handle many data types or sizes. A
  parameter can represent a type or a value, making components highly reusable.

  <InteractiveCode>
  ```systemverilog
  // Generic FIFO, parameterized by type T and depth D
  class fifo #(type T = int, int D = 4);
    T mem[D];
    int wptr = 0;

    function void push(T value);
      mem[wptr++] = value;
    endfunction
  endclass

  module demo;
    fifo #(byte, 8) byte_fifo;   // a specialization: T = byte, D = 8
    fifo            int_fifo;    // the default specialization: fifo #(int, 4)

    initial begin
      byte_fifo = new();
      int_fifo  = new();
      byte_fifo.push(8'hA5);
    end
  endmodule
  ```
  </InteractiveCode>

  ### The default specialization

  A generic class is not a type by itself; only a specialization is (§8.25). When every parameter has a default, the unadorned name means the **default specialization**, so `fifo int_fifo;` and `fifo #() int_fifo;` declare the same type. The standard's own example is `typedef vector my_vector; // use default size of 1`.

  The one place you must write `#()` is in front of the scope operator outside the class: use `fifo#()::some_static`, because `fifo::some_static` is illegal there (§8.25.1). A class whose parameters have no defaults has no default specialization, so every use must supply them.

  ### Each specialization is its own class, with its own statics

  `fifo#(byte, 8)` and `fifo#(int, 4)` are different types. They cannot be assigned to each other, and each has its own copy of every `static` property (§8.25).

  ```systemverilog
  class counter #(type T = int);
    static int created = 0;
    function new();
      created++;
    endfunction
  endclass

  module demo;
    counter #(int)  a, b;
    counter #(byte) c;
    initial begin
      a = new;  b = new;  c = new;
      $display("%0d %0d", counter#(int)::created, counter#(byte)::created);  // 2 1
    end
  endmodule
  ```

  UVM's factory relies on this: each `uvm_component_registry #(T, "name")` specialization keeps its own static registration for one class.

  ## Abstract Classes
  *IEEE 1800-2023, §8.21 Abstract classes and pure virtual methods*

  A class is **abstract** when it is declared with the `virtual` keyword: `virtual class driver;`. You cannot construct an abstract class directly, but a handle of its type can refer to any complete subclass object.

  A **pure virtual** method is a prototype with no body, written `pure virtual task run();`. §8.21 defines pure virtual methods as prototypes inside an abstract class (interface classes contain them too, §8.26). Writing one does not turn an ordinary class into an abstract one: the `virtual class` declaration does that, so declare the class `virtual` whenever it has a pure virtual method. A non-abstract subclass must override every pure virtual method it inherits.

  <InteractiveCode>
  ```systemverilog
  virtual class driver;            // abstract: virtual class
    pure virtual task run();       // prototype only; subclasses must implement it
  endclass

  class my_driver extends driver;
    virtual task run();
      $display("running");
    endtask
  endclass

  module demo;
    driver d;                      // handle to the abstract class
    initial begin
      // d = new();                // illegal: driver is abstract
      d = my_driver::new();        // typed constructor call (§8.8)
      d.run();                     // runs my_driver::run
    end
  endmodule
  ```
  </InteractiveCode>

  ## Common Pitfalls

  - Omitting default values makes every use spell out the parameters, and leaves no default specialization.
  - Parameter mismatches create a different type: a `fifo#(byte)` handle cannot hold a `fifo#(int)` object.
  - Expecting one static counter across all specializations: each specialization counts separately.
  - Forgetting to implement a `pure virtual` method in a non-abstract subclass prevents compilation.
  - Attempting to construct an abstract class with `new` results in an error.
