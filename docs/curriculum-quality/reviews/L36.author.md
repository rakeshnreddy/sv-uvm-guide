The width trap differs from the analyst's proposal: with a 64-bit bus (AxSIZE at most 3) a 13-bit sum cannot overflow, so the analyst's 13-bit example would not show the bug. The page uses the 12-bit "last byte offset" form, which is always true in 12-bit arithmetic (checked against §11.6.1 Table 11-21).
