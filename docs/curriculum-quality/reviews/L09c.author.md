## Expert items added (with sources)

1. **What else a shallow copy copies:** randomization state (RNG, `rand_mode`, `constraint_mode`, `randc` state), embedded covergroup set to null, instance constants duplicated, class follows the object. Sources: IEEE 1800-2023 §8.12 (step 2 and NOTE; `base3 = new base2` example), §18.14.3, §19.4, §8.19.
2. **Override rules that shape `copy()` and `clone()`:** matching argument types and names, covariant return types, `local` access to another instance, `:extends`/`:final` (tool support labelled "tool-dependent"). Sources: §8.20, §8.18.
3. **Deep copies of linked and shared structures:** back-pointers, shared sub-objects, uvm-core copier recursion tracking and `UVM_COPY_POLICY`, `UVM_REFERENCE` field flag. Sources: uvm-core 2020.3.1 `uvm_copier.svh` (`copy_object`), `uvm_object_defines.svh`.
4. **Ownership, cost and where copies belong:** publish-never-mutate / store-a-copy rule, copy at one end, cost (labelled tool-dependent). Sources: spine §5.2 #11; links to I-SV-5 mailboxes and I-UVM-2B.
5. **Why UVM separates `copy()` from `do_copy()`:** null check, default copier, flush, field automation then `do_copy`. Sources: IEEE 1800.2-2020 §5.3.8.1; uvm-core 2020.3.1 `uvm_object.svh`, `uvm_copier.svh`.
6. **Interview angles:** four attempt-first `InterviewQuestionPlayground` items (what `new h` copies; cloning through a base handle; mailbox in a shallow copy, kept from the old page; UVM `copy` vs `do_copy`). Strings carry no literal backticks (analysis cross-cutting 7).
