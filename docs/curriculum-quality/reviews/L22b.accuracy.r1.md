## Other checks (all correct)

- **Handshake table (:248-254).**
  - `start_item` is `wait_for_grant`, then `pre_do(1)`.
  - `finish_item` is `mid_do`, then `send_request`, then `wait_for_item_done`, then `post_do` (`uvm_sequence_base.svh:1095-1114`).
  - The request FIFO is a default `uvm_tlm_fifo` of size 1 (`uvm_sequencer_param_base.svh:261`).
  - `SEQNOTITM` and `SQRBADITMDN` are quoted correctly.
- **Ids (:297-301, :927, card 7).**
  - Ids start at -1 (`uvm_sequence_item.svh:54`; `uvm_transaction.svh:461`). `uvm_transaction::do_copy` does not copy them (:613-632).
  - `send_request` sets `transaction_id` only when it is -1, and always sets `sequence_id` (:318-325).
  - `SQRSNDREQGNI` and its message are right (:328).
- **`start()` (:364-375, :464-471, :907-915).**
  - The signature and defaults are right. Priority is 100 for a root sequence and the parent's for a child. `SEQPRI` fires below -1. `SEQ_NOT_DONE` comes from the one-key semaphore, which is released at :487, so a restart is legal.
  - `start()` calls `clear_response_queue()` and places its `#0`s as stated. The hook order is right. `SEQBDYZMB` is right.
- **`` `uvm_do `` family (:553-563, Q11, Q12, cards 5-6).**
  - `` `uvm_do `` is `` `uvm_create `` followed by `` `uvm_rand_send ``. Randomization failure raises the `RNDFLD` warning and the item is still sent.
  - A child is started with `start(get_sequencer(), this, PRIORITY, 0)`, and it is randomized only if `get_randomize_enabled()`.
  - The B.3.1.1–4 mapping is right. `` `uvm_do_with `` comes from the deprecated file.
- **Driver styles (:504-527) and expert corner cases (:917-923).**
  - `get` is `m_safe_select_item` followed by `item_done`, and `put` is `put_response`.
  - `try_next_item` repeats `wait_for_sequences` (an NBA wait) `m_wait_for_sequences_count` times. The default is 1, set from a resource. It reports `TRY_NEXT_BLOCKED` and returns null.
  - `get_current_item` matches §14.3.3.2 and the source comment "a driver that only calls get() will never show a current item".
- **Starting phase and default sequences (:933-938).** The page matches `uvm_sequence_base.svh:640-690` and `uvm_sequencer_base.svh` `start_phase_sequence`.
- **Make It Work (:633-836), read for syntax, declared names and behaviour.**
  - `timeunit` and `timeprecision` come first.
  - The typedef enum is declared before use.
  - `req`/`rsp` are members of `uvm_sequence` (`uvm_sequence.svh:59,66`) and of `uvm_driver` (`uvm_driver.svh:83-84`).
  - Initialized locals are automatic in class methods.
  - `` `uvm_error ``/`` `uvm_fatal ``/`` `uvm_info `` expand to `begin…end`, are written with no trailing `;`, and are safe in `if/else`.
  - `local::rd_addr` is right.
  - The traced output was checked: DRV at 10–80, RD_OK at 50–80, SEQ_DONE at 80, DRV printed at UVM_MEDIUM, and the context `uvm_test_top.env.agt.sqr@@seq` comes from `get_sequence_path()`.
