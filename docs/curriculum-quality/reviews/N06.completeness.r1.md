## Findings

### S3-1: Objective 2's "write" is never produced by the learner
- **Where:** `index.mdx:25` (objective 2); `index.mdx:1329-1334` (kata tasks)
- **Problem:** Objective 2 asks the learner to write a requester driver, a monitor and protocol assertions. Make It Work gives complete code for all three, which spine §5.4 accepts as exercise. In the kata, however, the learner writes a completer, a sequence and a subscriber. They only mutate the given driver, and never write driver, monitor or assertion logic themselves. The quiz tests only the debug half of the objective (Q6, Q7).
- **Fix:** Add one small production task to the kata, with its solution in the `<details>`. Options:
  - "convert `apb_driver` into the zero-idle driver of Push Further and show that `c_back_to_back` is hit" (best: it exercises the driver);
  - write an extra assertion, such as a read-side `PRDATA`-known check or a `PSLVERR`-low-outside-completion *cover/warning* (recommendation, not rule).
- **Source checked:** spine §5.4 (coverage); spine card objective 2; README depth ladder (practitioner layer).
