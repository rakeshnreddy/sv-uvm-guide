## Findings

| # | Sev | File:line | Problem | Fix | Source checked |
|---|---|---|---|---|---|
| 1 | S3 | index.mdx:911 | The page says to check the same-region rule "by recording the 1KB region (or the `HSELx` decode) of the first locked NONSEQ". §3.3 requires the same *slave address region*, and a slave may own many contiguous 1KB blocks (§4.2 sets only the minimum). A 1KB-block comparison fires on a legal locked sequence across two 1KB blocks of one slave, for example 0x3FC then 0x400 to a 4KB slave. That is a false alarm, against the lesson's own principle. | Compare the decoded slave (its `HSELx` or slave index from the address map) taken at the first locked transfer. Mention the 1KB block only as a conservative proxy that can raise false alarms. | IHI0033B.b §3.3, §4.2 |
| 2 | S4 | index.mdx:414 | IDLE "no transfer" is in quotation marks, but Table 3-1 says "Indicates that no data transfer is required." The BUSY quote in the same sentence is exact. | Quote it exactly ("no data transfer is required"), or drop the quotation marks. | IHI0033B.b Table 3-1 |
| 3 | S4 | index.mdx:480 | "An unaligned address makes the active byte lanes ambiguous (§6.1.1)." §6.1.1 does not mention unaligned addresses.
