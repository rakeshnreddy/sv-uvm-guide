## Hand traces I re-did (no simulator)

**Make It Work (`rb_*`).** Clock edges 5, 15, …; reset released by NBA at the 20 ns negedge; driver leaves its reset loop at 25 (samples `rst_n` = 1 with `#1step`). Drives after the 25 ns event land in that step's Re-NBA (§14.16), so each access transfers one edge later and `item_done()` follows one edge after that. Transfers: CTRL write 35, stray write 55 (unmapped, ERR set), INT_STATUS read 75 (rdata 1), INT_STATUS write 95, CTRL read 115 ('h3), INT_STATUS read 135 ('h0), CNT read 155. CNT: EN becomes 1 at the 35 edge, increments at 45…145 = 11 = 'hb. Predictor messages match `uvm_reg_predictor.svh` exactly (WRITE line carries `: updated value = 'h…` from `ir.get()`, which equals the mirror after `do_predict` because field `do_predict` sets `m_desired` too; READ line has no updated value). W1C info at 85: before 0, read 1, after 1. All three `mirror(UVM_CHECK)` calls pass (`exp` is captured before `XreadX`; CNT is volatile so the valid mask is 0). Clean summary is correct.

**Kata mutants.** A (no connect): W1C line `after=0`; CTRL check at 125 fails 'h3 vs 'h0 on en and led; INT_STATUS passes (mirror 0, DUT cleared). B (ERR as RW): INT_STATUS check fails read 0, mirrored 1. C (auto-predict 1 too): predictor sets 'h3 at 35, auto-predict XORs LED back at 45 → 'h1; CTRL check fails on led only. One `UVM_ERROR` each. Matches the worked solution table.

**Lab.** Starter (auto-predict 1, no connect, monitor publishes `wdata`): only CFG fails, at 185 ('hA5 read vs 'h55 mirrored). After FIX 1: double prediction; CTRL fails at 205 (led only, mirrored 'h1); IRQ survives because auto-predict runs after the predictor. After FIX 1+2: read items carry `wdata` = 0 (`XreadX` sets the value to 0 and `do_bus_access` packs it), so the predictor learns 0 at the 115 ns IRQ read while `read()` returns 1; `irq.mirror` fails at 145; CFG and CTRL checks pass because `exp` is saved before their own mispredicted reads. Solution: clean, ends with `[TEST] register checks complete`. Starter = solution minus header and three faults (diff checked). No fault or fix is named in the starter, README, description or steps.
