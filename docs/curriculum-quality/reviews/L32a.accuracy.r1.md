## Code and diagrams checked by inspection

  - APB3: 32+3+32+1+32+1 = 101 (Table 2-1 without PPROT and PSTRB).
  - AHB-Lite: 32+1+3+3+4+2+1+32+1+1+32 = 112 (the non-AHB5 rows of Table 2-2, plus HRDATA, HREADY and a 1-bit HRESP).
  - AXI4-Lite: 37+38+4+37+36 = 152 (Table B1-1).
  - AXI4: 63+39+8+63+41 = 214.
  - AXI4-Stream: 2+32+4+1 = 39.

  The Expected output matches. In the kata, four ID fields gain 4 bits each, and AXI4 has no WID, so the total is 230. Correct.

  - AHB INCR4: NONSEQ at 1, then SEQ at 2–4, with the address +4 each time; data at 2–5; HREADY high throughout.
  - Stream: transfers at 1, 3 and 4; TREADY low at 2 holds P1; TLAST with P2 at 4.

  All three are correct.
