## Note for the lead (outside this group's files)

- B-AXI-1 (index.mdx:514) describes its checker as "a module bound to every AXI interface with `bind`". That is fine when "interface" means the protocol port (B-AXI-1:919 binds into the module `axi_slave`). But a learner who binds that module into a SystemVerilog `interface`, as B-AXI-6 does with `axi_rd_if`, breaks IEEE 1800-2023 §23.11 rule 4. B-AXI-6:1575 states the rule correctly. Consider one clarifying sentence in B-AXI-1.
