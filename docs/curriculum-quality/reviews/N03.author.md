## Accuracy notes (verified against the sources)

- `+UVM_TESTNAME` precedence: F.7.3.1 steps d–e; uvm-core `run_test` (`RNTST`, `INVTST`, `TTINST`, `NOCOMP`).
- Default actions and default file handle 0: §6.3 items b and d; uvm-core `uvm_report_handler::initialize`.
- Verbosity ignored for warnings/errors/fatals: §6.3.3.3; macros use `UVM_NONE` (B.1.1.2–4).
- Counting every executed report, `UVM_NO_ACTION`/CAUGHT dropped before counting: uvm-core `uvm_report_server.svh` (identical to the 2020.3.1 tag on GitHub; diffed).
- Summary layout (`--- UVM Report Summary ---`, `%s :%5d`, `[%s] %5d`, quit-count lines), `reporter` name, `UVM/REPORT/SERVER` and `UVM/RELNOTES` IDs: uvm-core `uvm_report_server.svh`, `uvm_root.svh`.
- `+uvm_set_*` syntax: G.2.3–G.2.5 and uvm-core `uvm_cmdline_report.svh` (4 or 5 fields for verbosity, `_ALL_`, `|`-separated actions via `uvm_string_to_action`, `INVLCMDARGS`); applied in `uvm_component::new`.
- `+UVM_MAX_QUIT_COUNT` / `+UVM_TIMEOUT` applied in `uvm_root::build_phase`; default max quit count 0; `` `UVM_DEFAULT_TIMEOUT `` 9200 s; `PH_TIMEOUT` text from `uvm_phase_hopper.svh`.
- `$error` default fail action: IEEE 1800-2023 §16.3, §20.10; `$fatal` implies `$finish` (§20.10); `$finish` exit status not defined (§20.2).
- Hierarchical setters are Annex D.2.2 (normative); no `_hier` severity override exists.
- `uvm_top` is a uvm-core compatibility variable, so the page uses `uvm_root::get()` in code.
- Expected logs are illustrative (worked out from the source, not simulated) and say so; times shown in ns with a note on `%t`/`$timeformat` (§20.4.3).
