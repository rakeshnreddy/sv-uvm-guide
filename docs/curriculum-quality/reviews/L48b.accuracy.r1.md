## Findings

### 1. S3, references: GoldMine authors are wrong
- **Where:** `index.mdx:138` and `index.mdx:970`.
- **Problem:** The page credits GoldMine (DATE 2010) to "Sheridan, Liu and Vasudevan" and "D. Sheridan, L. Liu and S. Vasudevan". The DATE 2010 paper, IEEE Xplore 5457129, is by S. Vasudevan, D. Sheridan, S. J. Patel, D. Tcheng, W. Tuohy and D. R. Johnson. Lingyi Liu is not an author; Liu co-authored later GoldMine papers. The wrong attribution came from the verify report (V03) and was carried into the page.
- **Fix:**
  - Line 138: "GoldMine (Vasudevan et al., DATE 2010)".
  - Line 970: "S. Vasudevan, D. Sheridan, S. J. Patel, D. Tcheng, W. Tuohy and D. R. Johnson, 'GoldMine: Automatic Assertion Generation Using Data Mining and Static Analysis', DATE 2010."
- **Source:** IEEE Xplore 5457129 (author list, via web search 2026-10-11).

### 2. S4, precision: the width trap holds only for power-of-two depths
- **Where:** `index.mdx:189`.
- **Problem:** "If `fifo_count` is declared with `$clog2(MAX_DEPTH)` bits, it cannot represent `MAX_DEPTH`, and `fifo_count <= MAX_DEPTH` can never fail." This is true only when MAX_DEPTH is a power of two. For MAX_DEPTH = 5, `$clog2(5)` = 3 bits, which holds values up to 7, so the check can fail.
- **Fix:** Add "for a power-of-two MAX_DEPTH", or write "with `$clog2(MAX_DEPTH)` bits and MAX_DEPTH a power of two (as in most FIFOs)".
- **Source:** IEEE 1800-2023 §20.8.1 (`$clog2`); arithmetic.

### 3. S4, clarity: the TimingDiagram caption mixes two edge numberings
- **Where:** `index.mdx:194`.
- **Problem:** The caption says "this is clock edges 6 to 10 of the Make It Work run", then "At edge 1 … at edge 2 … At edge 3 … at edge 4". Those later numbers are the diagram's 0-based columns, while the bench table uses edges 6 to 10. A reader cross-checking the edge table can misread which edge failed. The values themselves are correct.
- **Fix:** Write "At diagram edge 1 (bench edge 7, 65 ns) … fails at edge 2 (75 ns) … edge 3 (85 ns) … edge 4 (95 ns)". Use the same wording in the marker labels if desired.
- **Source:** `DiagramKit.tsx:16, 84` (values[k] is sampled at edge k, 0-based); the trace above.
