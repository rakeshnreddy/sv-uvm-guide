# L45a visuals, navigation and accessibility review, round 1

Reviewer: visuals lens, 2026-10-11. Scope: `content/curriculum/T2_Intermediate/I-SV-8_Power_Intent_and_UPF/index.mdx` (rewritten), deck `content/flashcards/I-SV-8_Power_Intent_and_UPF.json`, author log `L45a.author.md`. No labs, no `public/visuals/` assets.

**Verdict: FAIL.** One S2 remains. It is a rendering defect in the kit diagram of the two-domain example: edge labels hide two arrows and print over two node names. The fix is one prop and one label, and I rendered it to confirm. Otherwise the visual design is strong. Every core concept has a picture. The three timing diagrams match the PMU code and both expected logs edge by edge. The visualizer is introduced, used for a prediction and debriefed, and its step numbers match the model. Navigation is correct.

- **Rendering.** I bundled `DiagramKit.tsx` with esbuild and rendered all nine diagrams with `react-dom/server`. I took screenshots at 900 px (light and dark) and 390 px with Playwright (scratchpad `L45avis/`), then re-rendered the proposed fixes (`L45avis/f1.png`, `f2.png`). Two kit details matter here. Container nodes draw only their `label`, never their `sublabel` (`BlockDiagram.tsx:279-283`).
- **Timing data against the code.** For the sequencing waveform (`:427-453`), edge k is 55 + 10k ns in `tb_top`. All of this matches the run 2 log (75 clamp, 105 X, 165 reset, 185 restore, 215 release). The retention waveform (`:302-321`) and both kata 1 diagrams (`:1030-1068`) follow the same convention, and each marker sits on the edge where the PMU makes its change, as the captions say.

For `off_before_iso`, X reaches the always-on side at step 2 and ctx returns. For `early_release` it is step 5, and for `save_after_off` step 6. `correct` is clean. The preset titles quoted on the page ("Power off before isolation", "Release isolation before restore", "Save after power-off", "Build your own") and the `top_out` row name match `PowerDomainVisualizer.tsx:175, 218, 271-277`.
- **Navigation.** `<BeforeYouStart />` closes Quick Take (`:27`). `<NextLesson />` is the last line (`:1200`), and there is no hand-written Next. All 7 in-content link targets exist as canonical `/curriculum/<Tier>/<Module>/index` files. The manifest prerequisites (F2A, F4A) match the References. No LabLink is used, which is correct because I-SV-8 owns no lab. Spine §3.5 pins nothing for I-SV-8, and `PowerDomainVisualizer.test.tsx` covers only the component.
- **Theme and accessibility.** The page has no inline SVG, images, `style=` or hard-coded colours. The kit provides `role`/`aria-label` and an sr-only value table for each timing diagram. Every diagram has a title and a caption. X is shown as a hatched pattern and the word X, not by colour alone.
