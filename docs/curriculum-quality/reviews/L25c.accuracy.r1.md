## Make It Work trace (by inspection against uvm-core 2020.3.1 and 1800-2023 §14.16)

- **Syntax and names.** Every identifier is declared; `do @(vif.mon_cb); while (...)` is a legal `do … while` with an event-control statement; `` `uvm_record_int `` expands to an `if … begin … end` block, so the missing semicolons are correct; `set_report_severity_id_override`, `get_objection().set_drain_time(this, 20ns)`, `set_recording_enabled_hier` all exist with these signatures. Parity: `parity = ^{addr,data}` gives even parity over `{addr,data,parity}`; the monitor's check matches.
- **Timing.** Clock edges at 5, 15, 25 …; reset released at 22. Driver: `get_next_item` returns at 22, `begin_tr` at 25, `end_tr` at 35 (item0); `get_next_item` for item1 returns at 35 after the edge, so the next drive is at 45 (45→55) and item2 at 65→75. Monitor: leaves the reset loop at 25 (event record at 25), samples item0 at 35 (record 35→45), item2 at 75 (parity error at 75, `addr='h18 data='ha2`). Sequence record 0→75 (`end_tr(this)` after the last `finish_item`). Drain 20 ns closes the last monitor record at 85. All match the page and the excerpt.
- **Excerpt line formats.** `CREATE_STREAM … T:TVM SCOPE:… STREAM:`, `OPEN_RECORDER … TYPE="Begin_No_Parent, Link"`/`"Begin_End, Link"`/`"Event"`/`"Error"`, `LINK … RELATION=child` after `OPEN_RECORDER`, `SET_ATTR … RADIX:UVM_STRING BITS=22` for `reset_released` (8 + 14) and `BITS=20` for `parity_error` (8 + 12), `inst_id` first in each `record()`, hex values without prefix, `CLOSE_RECORDER … TIME=`, `FREE_RECORDER`. All match the format strings. No `accept_time` or `initiator` attribute appears, which is correct: nothing calls `accept_tr`/`set_initiator` in this bench. The sequence record holds only `inst_id` (no `do_record` in `uvm_sequence_base`/`uvm_sequence_item`).
- **Debug challenge 3** traced: `start_item` sees automatic recording still on at the grant, opens `item0` on stream `seq`; `finish_item` re-checks after `item_done`, finds it off, never calls `end_tr`. Correct.
- **Debug challenge 1** traced: `record_event_tr`/`record_error_tr` never check `get_recording_enabled()`. Correct.
