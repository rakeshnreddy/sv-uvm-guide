### S4-2. The arrow-label wrap ignores the step-number prefix (kit, optional)

- **Problem.** `layoutSequence` wraps call and return labels at `floor(span/6.4)` = 22 characters (`diagram-layout.ts:320-321`). `SequenceDiagram.tsx` then prepends "N. " to the first line. Messages 2, 3 and 5 therefore draw a 25-character monospace first line, for example "2. super.new(name), first". At 10.5 px that is about 158 px inside a 160 px lifeline gap (x ≈ 246-404 between lifelines 245 and 405). It just fits, with no clipping or overlap on this page, but it has no margin.
- **Fix (kit, lead).** Subtract the prefix length (`String(step).length + 2`) from `maxChars` in `layoutSequence`. Nothing is needed on this page. An author workaround would be shorter labels such as "super.new(name) first".
- **Source checked.** `diagram-layout.ts:316-325`; `SequenceDiagram.tsx` arrow text (`{k === 0 ? prefix : ""}{line}`); computed `lines` for messages 2, 3 and 5.
