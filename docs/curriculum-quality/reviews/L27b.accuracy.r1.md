## Code traced by inspection

The Make It Work bench (`pred_demo.sv`):
- **Syntax.** All declarations come before statements.
- **Types and handles.** Every type and handle is declared. Adapter `reg2bus(const ref uvm_reg_bus_op)` and `bus2reg(uvm_sequence_item, ref uvm_reg_bus_op)` match the uvm-core prototypes. The config_db path `uvm_test_top.env.agent` matches the agent's `get(this, "", "vif", …)`.
- **Timing.** A transfer has three edges:
  1. E1: the driver drives at E1 + 1 ns.
  2. E2: the DUT and the monitor both see `sel` = 1 (the monitor's `#1step` sample). The monitor publishes and the predictor runs.
  3. E3: the driver calls `item_done()`.

  So explicit prediction lands before `write()`/`read()` returns, as the comment says. `sel` is high for exactly one sampling edge, so there is no double publish.
- **All four `+PRED` columns, traced through `uvm_reg::do_write`/`do_read` (auto-predict branch), `uvm_reg_predictor::write` and `XpredictX` (RW, RO, W1C, W1T):**
