## Expert items added (with sources)

1. **Expert: sampling corner cases.** Time-0 sampling and default sampled values (§16.5.1); an X→1 clock edge is a posedge (§9.4.2); glitching clocks are undefined, and the clock and disable condition use current values (§16.5); clocking-block inputs must use `#1step` (§16.5.1, §16.18); derived functions use `===`/`!==` (Annex F.3.4.4); `const'` and automatic variables (§16.5.1, §16.14.6.1).
2. **Expert: disable iff timing and reset strategy.** Disable window and nonvacuity (§16.12, §16.14.8 ag); a five-way comparison of `disable iff`, `default disable iff` (§16.15), an antecedent guard, `$assertoff`/`$asserton` and `$assertkill` (§20.11); `disable iff ($sampled(rst))` described precisely (start-of-slot value; still sees a pulse that lasts into a later time slot; §16.9.3).
3. **Expert: vacuity, statistics and pass actions.** Nonvacuity rules a, i, j, ag (§16.14.8); cover counters with disabled evaluations (§16.14.3); VacuousOff and NonvacuousOn, no change to statistics (§20.11); coverage status of implication covers labelled tool-dependent.
4. **Expert: procedural assertions, clock inference and stale values.** Inference conditions a–c with an async-reset `always_ff` (§16.14.6); explicit beats inferred (§16.14.6), inferred beats default (§16.16 c); current-value conditionals and static loop variables (§16.14.6.1); flush points and glitches (§16.14.6.2, §16.14.6.3).
5. **Expert: assertion control at scale.** `$assertoff`/`$asserton`/`$assertkill` ≡ `$assertcontrol(4|3|5, 15, 7, …)`, so `expect`, `unique` and `priority` are untouched (Tables 20-6, 20-7); Lock/Unlock; Off vs Kill for deferred and procedural queues (§20.11).
6. **Expert: performance and methodology.** Attempts per tick (§16.14.5); pending weak sequences are not failures, so bound the windows (§16.12.2); large dynamic data copies (§16.6); placement; assertions vs the scoreboard; formal reuse with `assume` and `restrict` (§16.14.2, §16.14.4).
