## Changes made in this run

- `uvm_queue` edge rule: the draft said every negative index is rejected. 1800.2 rejects only index ≥ `size()`; the negative-index rejection (and `delete(-1)` = all) is uvm-core. Reworded with both clauses.
- Expert item on the global pool: dropped an unverifiable claim about the global surviving several `run_test` calls per process; added the IEEE 1800-2023 §8.25 quotation for per-specialization statics (and §8.25 in References).
- Expert item on the pools: `uvm_transaction` does not create begin/accept/end up front; `accept_tr`/`begin_tr`/`end_tr` fetch them from the transaction's pool by name, which creates them. Reworded.
- Shallow copy: §8.12 defines the shallow copy of a class, not of an array; reworded to "the same handle-copying that §8.12 describes".
- Junior clarity: defined **verification IP (VIP)** and **objection** at first use (canonical "raise/drop" wording, spine §5.1; "vote" removed).
- Quiz: answer-key positions varied (Q6 key moved last, Q10 key first); Q10's stem no longer assigns through a function-call result (`q2.get(0).addr = …`), which is not a legal lvalue, and uses `it = q2.get(0); it.addr = 'h20;`.
- Interview playground: "The objection is about value" → "The case against it" (avoids the UVM term in a non-UVM sense).
