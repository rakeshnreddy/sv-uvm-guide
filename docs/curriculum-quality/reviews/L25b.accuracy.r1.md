## Claims verified correct (selection)

- `get()` inserts the Table 7-1 default with no message (1800.2 §11.2.2.4; uvm-core). A native associative-array read of a missing key adds nothing and "a warning shall be issued" (1800-2023 §7.8.6). A native `delete` of a missing key "issues no warning" (§7.9.2). `POOLDEL` is uvm-core only.
- `uvm_queue` rejects `index >= size()` (1800.2 §11.3.2.4, §11.3.2.6); the negative-index rejection is uvm-core. A native `insert` rejects only `index > size` (1800-2023 §7.10.2.2). `insert(0, x)` on an empty `uvm_queue` is ignored. 1800.2 §11.3.2.8 says the implementation "shall issue a warning" on an empty `pop_front`, while uvm-core calls the native method, which "may cause a warning" (§7.10.2.4).
- One global instance per specialization (1800-2023 §8.25, quoted verbatim). A typedef shares it, and a subclass inherits the base static. `uvm_event_pool::get_global_pool()` and `uvm_pool #(string,uvm_event#(uvm_object))::get_global_pool()` are different objects in uvm-core.
- The event and barrier pools create the object on a miss (§10.4.1.2.4, §10.4.2.2.4). A plain pool returns `null` for a class `T`. `wait_on`, `wait_trigger` and `wait_ptrigger` match §10.1.1.2.2/.4/.5.
- Barrier threshold defaults to 0 (§10.3.2.1). With threshold 0, `wait_for` returns at once (uvm-core: `1 >= 0`, then `m_trigger`). The traced waiter table is exact.
- Policy table: `do_copy` is shallow; the pool prints `[-key0--]` rows; the queue prints only a header; `convert2string` is `%p` for the queue and empty for the pool. `compare` returns 1 for the same specialization. Different specializations miscompare on type, and the message names the objects (`uvm_comparer.svh` type check). Neither class has `do_pack` or `do_record`.
- `uvm_transaction` fetches begin/accept/end from its own pool by name (`uvm_transaction.svh:713/818/849`).
- B.2.1.2: name-based factory lookup is not possible for `` `uvm_object_param_utils `` classes (quotation verbatim).
- `PH_TIMEOUT`, 9200 s default; `RNTST` text; report-summary format.
- Quiz answer keys Q1–Q10 and their feedback; the 15 flashcards; the kata and the debug-challenge solutions; all three interview keys.
