## Findings

1. **S3** `tasks-functions.mdx:525` (pitfall 8): "**A wait or a task call in a function.** Both are compile errors (§13.4)." This holds only for the function's own statements. Inside a `fork…join_none`, a function "may contain any statements that are legal within a task" (§13.4.4), and the page's own Q6 (line 901) keys `fork #5 ready = 1; join_none` as legal. L05.verify (Q6 row) asked for this qualifier in "the pitfall 'a function calling a task'". **Fix:** "**A wait or a direct task call in a function's own statements.** Both are compile errors (§13.4); only a process started by `fork…join_none` may wait or call a task (§13.4.4)." Source: §13.4 a-b, §13.4.4.
2. **S4** `tasks-functions.mdx:151` (VisualRecap `mistake`) and `:690` (Debug-it row "`@`, `#` or a task call inside a function"): the same qualifier is missing. Both sit next to qualified text (the line 145 rule and line 139), so the risk is low. **Fix:** say "directly in a function's body" in both. Source: §13.4, §13.4.4.
3. **S4** `tasks-functions.mdx:542`: "Every method is automatic, so the static-lifetime bug cannot happen inside class code". Line 778 qualifies this, because a local declared `static` inside a method is shared, but line 542 does not. **Fix:** "…so the default-lifetime bug cannot happen inside class code (a local you declare `static` in a method is still shared)". Source: §13.3.1, §13.4.2, §6.21.
4. **S4** `tasks-functions.mdx:750`: "it may call only other constant functions". This is incomplete. §13.4.3 also allows system functions that are legal in a constant expression (such as `$clog2`) and built-in methods on the function's own local variables. **Fix:** "…may call only constant functions, constant system functions such as `$clog2`, and built-in methods on its own locals". Source: §13.4.3.
5. **S4** `tasks-functions.mdx:508`: "(not inside the initial block, where the initializer would need static)". `automatic` would work just as well (§6.21 `top_legal`), and an automatic queue can still be passed by `ref`. **Fix:** "would need `static` or `automatic`". Source: §6.21.
6. **S4** `content/flashcards/F2D_Tasks_Functions.json` f2d-tf-1: "its own statements cannot wait (`#`, `@`, `wait`, `fork…join`)". The parenthesis reads as the full list but leaves out `fork…join_any`, `##`, `wait fork`, `wait_order` and `expect`. **Fix:** add "such as" before the list, or add `fork…join_any`. Source: §13.4 a.

No other errors were found. No S1 or S2 issue remains, and the rewrite introduced no new S1 or S2 error.
