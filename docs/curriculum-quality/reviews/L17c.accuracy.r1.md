## How I checked

**IEEE 1800-2023 text** (`scratchpad/audit/t1_lrm_clean.txt`). I read each clause the page cites, and the clauses its claims depend on.

Mailboxes, §15.4 to §15.4.9:
- bounded and unbounded queues; `new(int bound = 0)`, where 0 means unbounded and "Negative bounds are illegal";
- `num()` is "valid only until the next get() or put()";
- put stores in "strict FIFO order" and suspends a caller while the mailbox is full;
- `try_put` returns a positive integer, or 0 when full;
- `get`, `peek`: a run-time error on a type mismatch; "The mailbox waiting queue is FIFO… only that their arrival order shall be preserved";
- `try_get`, `try_peek`: positive, 0 or negative;
- a `peek()` can unblock more than one process;
- the compiler checks that the arguments of a parameterized mailbox's methods "use argument types equivalent to the mailbox type".

Built-in classes and Annex G.4:
- §15.2: the built-in classes "can be used as base classes… reside in the built-in std package… can be redefined by user code";
- §26.7;
- Annex G.4: `class mailbox #(type T = dynamic_singular_type)`, with eight non-virtual prototypes and `ref` on get/peek/try_get/try_peek;
- Annex P: "singular… any data type except an unpacked structure, unpacked union, or unpacked array".

Other clauses:
- §4.7.
- §5.7.1: unsized decimal numbers "shall be treated as signed integers".
- §6.24.2.
- §8.4: null-handle access is illegal and indeterminate; `==`/`!=` are valid on handles.
- §8.12: `new p1` is a shallow copy.
- §8.14, §8.20, §8.29.
- §9.4.2: changes to data members referenced by a method "shall cause the event expression to be reevaluated".
- §9.6.1: "Simulation automatically terminates when there is no further activity of any kind".
- §9.6.3.
- §13.4: rule b, plus the §13.4.4 exception.
- §13.5.2: "matched with equivalent data types… No casting".
- §9.3.2: the ref-formal restriction inside `fork…join_any`. It does not apply to the kata's `output` formal.
- §14.3: default input skew 1step, default output skew 0.
- §14.13: input sampling in the preceding Postponed region.
- §14.16: zero-skew drives scheduled in "the Re-NBA region of the time step corresponding to the clocking event".

All the clause titles listed under References match the standard. For §26.7, the table-of-contents line in the extracted text is offset, but the body heading is "26.7 The std built-in package".
