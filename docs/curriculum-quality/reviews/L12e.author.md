### Objectives (page subset of module objective 5)

1. **Predict** what a failed `randomize()` returns and leaves in the object, and **decide** whether a value that never appears is a solver failure or a silent coverage hole.
2. **Debug** a failing `randomize()` by isolating a minimal conflicting set with `constraint_mode()`, `rand_mode()` and `randomize(null)`, and use the specification to decide which member is wrong.
3. **Diagnose** failures that are not plain contradictions: signed or narrow arithmetic, inherited or overridden constraints, and implicit solve orders.
4. **Write** randomization calls whose failures cannot pass silently, in plain SystemVerilog and UVM, and **explain** when a recorded seed still reproduces a failure after the code changed.
