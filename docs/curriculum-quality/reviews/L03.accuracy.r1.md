### Code and expected outputs (traced by hand; no simulator)

- **Dynamic-array demo (:156-190).** `{0,10,20,30}` → `new[6](buffer)` `{0,10,20,30,x,x}` → `new[2](buffer)` `{0,10}` → `new[3]` `{x,x,x}`; `lens = {3,1,4}` then `{lens,5}` gives `{3,1,4,5} size=4`; `delete()` gives 0. Unpacked array concatenation into a dynamic target is legal (§10.10) and resizes it (§7.6). Matches.
- **first/next walk (:336-368).** `Gamma, alpha, beta`, then `next` returns 0 and leaves `key = beta`; `num() = 3`. The `if … do … while` form is the LRM's own (§7.9.6). Matches.
- **Methods demo (:397-447).** sum 31; `bytes.sum()` 300 → 44; `with (int'(item))` 300; count of `item > 4` = 3; `find_index` `{4,5,7}`; `max` `{9}`; 7 unique values; `item == item.index` only at index 1; sort, rsort and reverse lines all correct. The order caveat for `find_index` matches §7.12.1.
- **By-value vs `ref` (:536-563).** `{1,2,3}` then `{0,2,3}`. `ref` in an automatic function with an equivalent queue type is legal (§13.5.2, §6.22.2(e)).
- **Make It Work tracker (:700-800).** All 8 trace rows, `MISMATCH id=1 exp=000000a1 act=000000a2`, `MISMATCH … exp=000000a2 act=000000a1`, `mem[1000]=deadbeef mem[2000]=xxxxxxxx`, `PENDING id=3 count=1`, `SCB_SUMMARY matches=1 mismatches=2 pending=1`; the clean run gives `matches=4 mismatches=0 pending=0`. `exp_by_id[id] = {}` allocates by assignment (§7.8.7, §10.10). `$error` is legal in a function and in a `final` block (§9.2.3: function-legal statements only).
- **Kata solution (:1159-1253).** Both runs re-traced: `A: matches=2 mismatches=2 pending=0` / `B: matches=4 mismatches=0 pending=0`, and `A: matches=0 mismatches=3 pending=1` / `B: matches=1 mismatches=2 pending=1`, with the error lines in the printed order. Matches.
- **Two-pass and one-pass cleanup traces (:621-635, :865-884), aliasing trace (:639-652), slice answers (:226-240), query-function table (:520-526), debug challenge answers (:1291-1303).** All correct. The empty-queue row (`$right` −1, `$increment` −1, `$low` 0, `$high` −1) follows the 2023 rule "For a queue or dynamic array dimension, `$increment` shall return −1" (§20.7). The associative rows follow §20.7's integral-index rules (`$right` = highest possible index, `$low`/`$high` = `'x` when empty).
