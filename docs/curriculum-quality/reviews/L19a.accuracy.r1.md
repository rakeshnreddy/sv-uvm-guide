## Make It Work bench (checked by inspection)

Legal syntax and declared names throughout (enum, dist constraints, embedded covergroup with `iff` and explicit bins, `copy()`, mailbox `try_get`/`try_put`/`get`/`put` usage, `continue` in `forever`, `disable fork` scope, `bind … (.*)` resolved in `sync_fifo`, interface passed to `virtual fifo_if` arguments). Behaviour matches the prose:
- Driver drives only through `drv_cb` (zero output skew, Re-NBA of the clocking-event time step, §14.16), one operation per clock, so `wr_en` and `rd_en` are never both high; the monitor samples through `mon_cb` (1step) and so sees the pre-edge values the DUT flops used.
- Registered read: the monitor defers an accepted read one edge and publishes it before that edge's write; since there is one operation per clock the scoreboard sees operations in DUT order. Write acceptance `!full` and read rejection on `empty` match the DUT's conditions; the scoreboard's `model.size() < depth` / `== 0` checks agree with the DUT occupancy at every edge.
- 1000 random + 8 drain items give exactly one observation each, so `matches=1008`, `pending=0`, `PASS=1008 FAIL=0`; output is labelled illustrative and the coverage caveat (write-rejected cross bin depends on the random walk) is stated.
- Mutants 2 and 3: symptoms and causes are correct (rd_data is the previous read's value or reset 00; `gen.run` returns with the last item still in the bound-1 mailbox).
