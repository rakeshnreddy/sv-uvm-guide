## Not findings (checked and correct)

- **Packages and virtual interfaces:** the package-level `virtual axi_wr_bfm` and `axi_wr_monitor proxy` (circular package ↔ interface) is the DVCon 2011 Sample A.4 pattern, and is not a hierarchical reference under §26.2. The BFMs have only signal ports, so §25.9 is satisfied.
- **Clocking-block drives at time 0:** the drive in `wait_for_reset` matures at the next clocking event (§14.16) and is harmless during reset.
- **Monitor start-up:** `wait (proxy != null)` resolves at time 0 after `connect_phase`.
- **Test end:** the `while (observed < n) @(burst_observed)` end-of-test has no lost-event race, because the condition is re-tested before each wait.
- **SV-Connect expert snippet:** `start_burst` returns at once, and `@(done_ev)` is armed before any clocked completion can occur.
- **Interview items:** all three have correct keys.
- **Kata `send` with `gap = 0`:** `cb.valid <= 1'b0` followed by `cb.valid <= 1'b1` in the same time step is well defined, because the last drive wins (IEEE 1800-2023 §14.16.2).
- **Pipes at line 403:** this passage states deferred visibility correctly. Only the Expert restatement (F9) is reversed.
