## What is strong

- **The fix to C-01 is the right one.** The checker now encodes the specification: a reset wipes a restore only after a power loss. It is no longer a comment that the code contradicts. The four-item rule on the page, the lab Step 3 text and the Kata 2 key all agree, and every trace is unchanged.
- **Abrupt power loss is now taught end to end.** The variant runs the abort, the flush and the drop count in one traced run. It names the zero-time loop, and it ties the loop to a quiz item (Q13) and a debug-table row. Learners rarely meet this transfer-level detail elsewhere.
- **Coverage teaches the difference between "where" and "how".** The two trace tables and Q12 show why state coverage closes while the order of the actions does not. Card e_pwr_1_20 reinforces it. This is staff-level material, presented in small steps.
- **Practice is complete and well aligned.** Every objective is quizzed and exercised. Kata 2 now has the learner write a sequence, an assertion and a coverpoint, then predict. The lab has a checkable expected result for every step.
