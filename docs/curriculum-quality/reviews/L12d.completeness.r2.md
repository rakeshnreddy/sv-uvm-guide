## Findings

### S3

**F1. S3 randomization-methods.mdx:282-311. The before/after drill asks the learner to predict against "the original code", which is not on the page yet.**
- *Problem.* The intro (:282) and the diagram show only the creation order: `p.srandom(1234)`, `a`, `s = new(42)`, `b`. Edit 6 (:310, and row 6 at :323) says "before the loop", but no loop has been shown. The randomize loop first appears in Make It Work, at :468, about 160 lines later. A junior reading in order has to guess that each object is randomized three times in a loop, so the "predict first" step rests on code the learner has not seen.
- *Fix.* Before the predict list, add a 6-8 line `// snippet` of the setup, for example `p.srandom(1234); a = new(); s = new(42); b = new(); repeat (3) begin` followed by the three checked `randomize()` calls and `end`. Or reword :282 to say that the block "then randomizes a, s and b three times in a loop".
- *Source checked.* README §Target lesson 4 and Tone ("Concepts are built in small steps … Nothing is skipped"); spine §5.3 (Visuals: introduce, predict, debrief).
