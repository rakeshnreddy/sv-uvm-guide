## Verified as correct (no action)

- **The three-file model.**
  - Syntax matches the PSS 3.0 BNF:
    - `resource dma_chan_r { }`, `pool [2] dma_chan_r chan_p;`, `bind chan_p *;`, `lock dma_chan_r chan;`;
    - `rand bit[32]`, the unnamed `constraint { … }` and the single-item `constraint bursts in [4..32];`;
    - `[a..b]` ranges, labelled `c0: do dma_subsys_c::dma_copy_a;`, `extend action dma_subsys_c::dma_copy_a { … }` inside `package`, and triple-quoted templates.
  - `{{chan.instance_id}}` is a scalar reference in the action's scope (§22.5.3). The extension's exec blocks are woven into the type (§20.2, §22.1.4.3).
  - The SV template is legal inside a class task: a `begin` block with an initialized automatic declaration, `type_id::create`, `start(seqr, this)` and `32'h8100_0000`. 0x81000000 lies outside both windows.
- **Expected output.**
  - `c1`: chan 0, src 0x20000000, dst 0x80000400, len 256. `c0`: chan 1, src 0x20003C40, dst 0x80100000, len 1024.
  - Both satisfy every constraint: ranges, 64-byte alignment, the `src` bound and both window bounds. `bursts=12` is in [4, 32].
  - 0x20000000 = 536870912 and 0x80000400 = 2147484672. The write ranges at `:346` are exact.
  - `bit` values print as unsigned decimal (§22.5.3.2).
- **Pool [1] prediction** (`:317`, Q7, card 7): illegal per §12.3.4 b and Example 65, and §14.2.1. Q7's distractor feedback is correct.
- **SystemVerilog target at SoC level** (`:193`, `:376`, card 4) matches uvm-core 2020.3.1:
  - `start(null, this)` takes the parent's (virtual) sequencer;
  - a `p_sequencer` cast gives `DCLPSQ`;
  - without one, `start_item()` waits for a grant that only a driver's pull issues, until `PH_TIMEOUT`.
- **Executors and yield** (`:378`, `:394-396`, card 11): the quotes are exact (§24.6, §24.6.1.1, §24.6.1.2, §24.6.2). `yield;` is limited to target exec blocks and functions (§22.7.14.1 a), and only yielding inside a C template body is labelled tool-dependent.
- **Other claims.**
  - Coverage: Clause 18 data coverage, Clause 19 behavioral coverage new in 3.0, run-time sampling (§1.4), and merging labelled tool-dependent.
  - §22.8's three flows.
  - §24.7 region traits, and §24.8.5 disjoint concurrent allocations (the basis of "the tool allocates buffers so that parallel actions cannot overlap").
  - Kata: DECERR on B per IHI0022E §A3.4.4, and the `instance_id` equality constraint per Example 117.
- **Quiz.** Q1–Q8 each have exactly one `correct: true`, and every key matches the sources. Q2's "2.1 approved in October 2023" matches the 3.0 front matter.
- **Flashcards 1–16.** All are accurate. Card 16's wrap argument matches §8.7.1 (with an unsized constant of only 32 bits the sum can wrap, so "can" is the right word). Card 13 matches the explicit-versus-auto prediction rule.
- **References.** Every cited section exists with the stated title or content. "§22.1.1 exec block rules" is the list under §22.1.1 "Syntax".
