# G29 Interview question banks: analysis

Analyst: G29. Date: 2026-10-03. Scope: the six banks in `content/interview-questions/` (59 questions). Read-only on all content.

**How the banks are used today.** The schema is `src/types/interview-question.ts`. Two tests read the banks: `tests/interview-questions/bank-schema.test.ts` (field shape, levels, categories, counts, unique ids) and `tests/amba-flashcards.spec.ts:57-71` (AMBA bank has at least 5 complete questions). `tests/qa/scheduling-semantics-lint.spec.ts` also scans the banks for five known scheduling misconceptions. All three pass (323 tests, run 2026-10-03), but they check shape only. **No route, component or lesson loads the banks** (`grep -rli interview src/app` returns nothing; only the type file references `InterviewBank`), so learners cannot reach any of the 59 questions. The 26 lesson files that use `<InterviewQuestionPlayground>` are a separate, inline system.

**How I verified.** Every normative claim was checked against:
- IEEE 1800-2023 (`scratchpad/audit/t1_lrm_clean.txt`);
- uvm-core 2020.3.1 (`src/**/*.svh` fetched from the `2020.3.1` tag; clause numbers from the `@uvm-ieee 1800.2-2020` annotations);
- Arm IHI0022E (AXI/ACE, `scratchpad/audit/axi.txt`) and Arm IHI0033B.b (AHB5, `scratchpad/audit/ahb5.txt`);
- Arm IHI0050E.b (CHI). A PDF copy from an earlier session is in this session's `tool-results/webfetch-1791063688327-k7ds9x.pdf`; my extracted text is `scratchpad/g29/webfetch-1791063688327-k7ds9x.txt`.

APB (IHI0024) and SCE-MI were not available, so claims about them are marked unverified. "Unverified" means I could not check the claim; it does not mean the claim is wrong. `curriculum-spine.md` does not exist yet, so module mapping uses the current folder IDs.

Headline findings:
1. **The banks cannot be reached.** No page renders them and no lesson links to them, including B-AMBA-F3 "AMBA Interview & Debug Clinic". This is a navigation dead end (S2, cross-cutting; see Requests).
2. **Seven S1 errors teach a wrong model or carry a wrong answer key:**
   - packed-array slicing and an "unpacked arrays cannot be sliced" rubric (SV);
   - analysis ports "copy" the item, drain time as a "safety net", and reversed agent roles in the DMA environment (UVM);
   - an SVA property that does not check "exactly 2 cycles" (SVA);
   - a coherency invariant that misses UniqueDirty (AMBA).
3. **Citations are unreliable.**
   - Every IEEE 1800.2-2020 clause number in the banks is wrong. For example, "§3 (Factory)" should be 8.3, and "§9.4 (Objections)" should be 10.5.
   - AXI citations mix IHI0022E (correct where used) with IHI0022H numbers that are unverified and in places impossible ("§A10 (ordering)").
   - CHI citations name Issue F sections that do not match Issue E.b.
   - Four of six debug questions cite only unnamed "(secondary)" sources.
4. **Fixes from the 2026-10-03 audit still hold.** I re-verified these: `sv-scheduling-regions`, `sv-clocking-block-race`, `sva-concurrent-vs-immediate`, `sva-past-sampling`, `amba-ace-snoop-flow`, the `amba-chi-node-roles` RN-I definition, the `amba-ahb-hready-hreadyout` citations, and the `amba-bridge-4kb-split` 1KB/4KB logic.
5. **The banks lack depth and range for learners.**
   - Only 2 of 59 answers contain code. "coding" items have no code, and "waveform-debug" items have no waveform.
   - Answers average 390–810 characters and give no follow-up probes.
   - AMBA and SoC have no junior questions.
   - 29 of 69 modules have no question at all (see Coverage gaps).
