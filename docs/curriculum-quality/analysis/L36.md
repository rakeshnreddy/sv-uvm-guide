**Expert: absent.** Add these as `### Expert:` subsections. All are verified.
1. **Two ways to signal an unaligned start** (A3.4.3 "Unaligned transfers").
   - A master can use an unaligned AxADDR, or an aligned AxADDR plus byte strobes.
   - The low-order address bits "must be consistent with" the strobes, and the slave "is not required to take special action" on alignment.
   - So the 4KB check and the memory model must handle both forms. Leading zero strobes are legal.
2. **What an interconnect may do to your burst** (A4.3.1; A3.4.1 note; A7.1).
   - A Modifiable transaction may be split or merged, may read more data, and may write a wider range under WSTRB. It may change AxADDR, AxSIZE, AxLEN and AxBURST, so a WRAP can become INCRs.
   - No modification may access "a different 4KByte address space" or split a single-copy-atomic access.
   - A Non-modifiable transaction must not be split or merged, except an INCR longer than 16 transfers.
   - So an end-to-end scoreboard compares bytes per address, not transactions.
   - Which transformations an interconnect performs (for example splits for AXI3 slaves, or WRAP to INCR) is implementation-defined: label it and read the IP documentation.
3. **Exclusive accesses tighten the rules** (A7.2.4).
   - The total number of bytes is a power of two, at most 128.
   - The address is aligned to that total.
   - The AXI4 burst length is at most 16.
   - The exclusive read and write use the same address and identical control signals.
   - Link B-AXI-4.
4. **Read-sensitive targets** (A3.4.1).
   - Bursts never terminate early. A master that discards read data still completes every transfer, and discarding data from a FIFO loses it.
   - Use a burst length that exactly matches the data needed.
5. **Width conversion and byte invariance.**
   - The A4.3.1 note: downsizing below AxSIZE must modify the transaction.
   - A3.4.3 "Byte invariance": a byte transfer to a given address uses the same data wires, whatever the endianness.
   - Link B-AMBA-F1.
6. **Legal-by-construction stimulus and burst coverage.**
   - Write the 4KB constraint as `((addr[11:0] >> size) << size) + ((len + 1) << size) <= 4096`.
   - It stays 32 bits wide because the literals are unsized. Constraint expressions are ordinary expressions (§18.5), and relational operands are sized to the wider operand (§11.6.1, Table 11-21).
   - If every literal is sized (`8'd1`, `13'h1000`), the expression is 13 bits wide. A 256-transfer burst of 128-byte transfers (32768 bytes) then wraps to 0 and "passes".
   - Solver speed with random shift amounts is tool-dependent: label it and measure.
   - Coverage: burst type × length bins × narrow or full width × aligned or unaligned × ends at the page end × sparse, full or zero strobes (§19.5, §19.6).
7. **Checker versus scoreboard.**
   - Take a driver that sends transfer 2 of an INCR from 0x1003 to address 0x1007. It drives `4'b1000`.
   - That is a legal sparse strobe for the real Address_2 = 0x1004, so every protocol assertion passes.
   - Only a byte-level scoreboard sees the missing bytes.
8. **Interview angles**, attempt-first with `InterviewQuestionPlayground`. The questions are in the Assessment plan.

#### `## Quick Take`

The `<QuickTake>` box may stay inside the H2 for the six facts; fix :24 to name INCR and WRAP only.

- **What it is:** the arithmetic that turns one AW or AR request (AxADDR, AxLEN, AxSIZE, AxBURST) into the address and byte lanes of every transfer, plus the rules that make a burst legal.
- **Why it matters:** drivers, monitors, scoreboards and protocol checkers all recompute it. An off-by-one or an unaligned start silently writes the wrong bytes while every handshake looks clean.
- **The Analogy:** a burst books a run of equal-width seats in a theatre row:
  - AxSIZE is the seat width and AxLEN+1 the number of seats;
  - FIXED re-books the same seat, INCR moves along the row, and WRAP circles inside one aligned block;
  - the 4KB boundary is the aisle between two ushers (slaves), and an INCR booking must not continue across it.

  *Where it breaks:* an unaligned first booking covers only part of its seat, and a seat has no equivalent of a sparse WSTRB.
- **You will be able to:** see Objectives below.
- **Before you start:** see Navigation and references below.

**`### Example: burst math a driver, monitor and checker can share`**

The expected output is illustrative unless the author runs it; say which simulator if they do. I checked every value with the A3.4.1 model.

```systemverilog
// compile
// IHI0022E A3.4.1 burst equations, shared by driver, monitor and checker.
package axi_burst_pkg;
  localparam int unsigned DATA_BYTES = 8;  // 64-bit data bus

  // AxBURST encodings (Table A3-3); 2'b11 is reserved.
  typedef enum logic [1:0] {FIXED = 2'b00, INCR = 2'b01, WRAP = 2'b10} burst_e;

  // Address_N, N = 1 .. AxLEN+1 ("Burst address", A3.4.1).
  function automatic logic [31:0] beat_addr(
    input logic [31:0] start, input logic [2:0] size,
    input logic [7:0] len, input burst_e burst, input int unsigned n);
    int unsigned nbytes  = 1 << size;
    int unsigned total   = nbytes * (len + 1);
    logic [31:0] aligned = (start / nbytes) * nbytes;
    logic [31:0] wrap_lo = (start / total) * total;  // Wrap_Boundary
    logic [31:0] addr;
    if (n == 1 || burst == FIXED) return start;  // FIXED never moves
    addr = aligned + (n - 1) * nbytes;           // later transfers are aligned
    if (burst == WRAP && addr >= wrap_lo + total) addr -= total;
    return addr;
  endfunction

  // Lower_Byte_Lane .. Upper_Byte_Lane of the transfer at addr (A3.4.1).
  function automatic logic [DATA_BYTES-1:0] active_lanes(
    input logic [31:0] addr, input logic [2:0] size);
    int unsigned nbytes  = 1 << size;
    int unsigned aligned = (addr / nbytes) * nbytes;
    int unsigned lower   = addr % DATA_BYTES;
    int unsigned upper   = aligned % DATA_BYTES + nbytes - 1;  // container end
    logic [DATA_BYTES-1:0] lanes = '0;
    for (int unsigned lane = lower; lane <= upper; lane++) lanes[lane] = 1'b1;
    return lanes;
  endfunction

  // Only INCR can cross 4KB; count from Aligned_Address (A3.4.1).
  function automatic bit crosses_4kb(
    input logic [31:0] start, input logic [2:0] size,
    input logic [7:0] len, input burst_e burst);
    int unsigned nbytes  = 1 << size;
    logic [31:0] aligned = (start / nbytes) * nbytes;
    logic [31:0] last    = aligned + (len + 1) * nbytes - 1;
    return burst == INCR && start[31:12] != last[31:12];
  endfunction

  // Transfers an INCR burst from start can make before the next 4KB
  // boundary. The caller caps it at 256 (AXI4) or 16 (AXI3).
  function automatic int unsigned beats_to_4kb(
    input logic [31:0] start, input logic [2:0] size);
    int unsigned nbytes = 1 << size;
    int unsigned off    = (start[11:0] / nbytes) * nbytes;  // aligned page offset
    return (4096 - off) / nbytes;
  endfunction
endpackage

module tb_top;
  import axi_burst_pkg::*;
  int unsigned pass_n, fail_n;

  function automatic void check_eq(input string what, input logic [63:0] got,
                                   input logic [63:0] want);
    if (got === want) pass_n++;
    else begin
      fail_n++;
      $display("FAIL %s: got 0x%0h, expected 0x%0h", what, got, want);
    end
  endfunction

  initial begin
    check_eq("INCR 0x1003 N=2", beat_addr(32'h1003, 3'd2, 8'd3, INCR, 2), 32'h1004);
    check_eq("INCR 0x1003 N=4", beat_addr(32'h1003, 3'd2, 8'd3, INCR, 4), 32'h100C);
    check_eq("WRAP 0x0FFC N=2", beat_addr(32'h0FFC, 3'd2, 8'd3, WRAP, 2), 32'h0FF0);
    check_eq("WRAP 0x0FFC N=4", beat_addr(32'h0FFC, 3'd2, 8'd3, WRAP, 4), 32'h0FF8);
    check_eq("lanes 0x1001 4B", active_lanes(32'h1001, 3'd2), 8'b0000_1110);
    check_eq("lanes 0x1004 4B", active_lanes(32'h1004, 3'd2), 8'b1111_0000);
    check_eq("0x0FF0 x4 legal", crosses_4kb(32'h0FF0, 3'd2, 8'd3, INCR), 0);
    check_eq("0x0FF4 x4 cross", crosses_4kb(32'h0FF4, 3'd2, 8'd3, INCR), 1);
    check_eq("0x0FFE x1 legal", crosses_4kb(32'h0FFE, 3'd2, 8'd0, INCR), 0);
    check_eq("WRAP no cross",   crosses_4kb(32'h0FFC, 3'd2, 8'd3, WRAP), 0);
    check_eq("split 0x0FF3 8B", beats_to_4kb(32'h0FF3, 3'd3), 2);
    $display("PASS=%0d FAIL=%0d", pass_n, fail_n);
    $finish;
  end
endmodule
```

5. Legality: length, WRAP alignment, AxSIZE, the 4KB rule for INCR.
6. If a needed transfer crosses 4KB, split it.

Add five cards (15 in total, within the spine's 8–15):
- **b-axi-2-11** (misconception 1). Q: "INCR, AxSIZE = 2, four transfers from 0x1003: the addresses?" A: "0x1003, 0x1004, 0x1008, 0x100C. Address_N = Aligned_Address + (N−1) × Number_Bytes for N ≥ 2 (A3.4.1); adding 4 to 0x1003 each time is the classic driver bug."
- **b-axi-2-12** (misconception 3). Q: "Must WSTRB equal the active lanes?" A: "No. WSTRB may be any subset of the active lanes, including all zeros; a strobe on a lane outside them is illegal (A3.4.3). A checker tests `(WSTRB & ~lanes) == 0`."
- **b-axi-2-13** (misconception 2). Q: "Can a WRAP or FIXED burst cross 4KB?" A: "No. A legal WRAP stays inside its aligned window of at most 16 × 128 = 2048 bytes, and FIXED never moves, so a 4KB checker tests INCR only."
- **b-axi-2-14** (must-cover). Q: "A master writes 100 bytes from 0x0FF3 with 8-byte transfers. What does it issue?" A: "Two INCR bursts: AWADDR 0x0FF3, AWLEN 1 (13 bytes, up to 0x0FFF), then AWADDR 0x1000, AWLEN 10 (87 bytes). Transfers before the boundary = (0x1000 − Aligned_Address 0x0FF0) / 8 = 2."
- **b-axi-2-15.** Q: "How many W transfers does a write burst have, and when is WLAST HIGH?" A: "AxLEN + 1. The master drives WLAST on the last one (A3.2.2), and the slave drives RLAST on the last read transfer. Bursts cannot end early: to write less, the master drives all-zero strobes for the rest (A3.4.1)."
