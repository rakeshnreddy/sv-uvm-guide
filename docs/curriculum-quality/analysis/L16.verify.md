**Precision rules from this verification:**
- `##0` never waits only in a singly clocked sequence. Across clocks it waits for the next tick of the new clock unless the two ticks coincide (§16.13.1).
- `first_match` changes results in an antecedent (§16.12.7) and before more sequence. It does not change a bare consequent (§16.12.2).
- Keep §16.12.21's levels separate from the visualizer's PENDING status. An open strong obligation is "Pending"; an open weak attempt "Holds (but does not hold strongly)".
- A checker declared in a package inherits no default clocking or disable, because packages cannot declare them (A.1.11). Use clock formals, or defaults of `$inferred_clock`/`$inferred_disable` (§17.4, §16.14.7).
- Bind a package checker as `chk_pkg::name` (§17.3), because `$unit` declarations are not visible in a bind (§23.11). Compile the package first (§3.12, §26.3).
- Checkers have no parameter ports and no `parameter` or `localparam` items (§17.2, A.1.8). Pass constants as arguments; the bind actuals resolve in the target (§23.11).
- In a checker, `always_ff` allows only nonblocking assignments (§17.7.1). Blocking assignments are allowed only in `always_comb` and `always_latch` (§17.5).
- Cite the unique-semantic-leading-clock rule as §16.16 item e), with the definition in §16.16.1.
