3. **B-AXI-3: the A3.3.1 AXI4 write-response note** ("the slave takes responsibility for hazard checking") is the clean bridge from A5.3.4 to A6.4. Add it to Rule 4 and to the responsibility matrix.
4. **B-AXI-3: the Rule 4 scoreboard policy needs a fourth case.** A read issued after B can still legally return a value written later by another master or ID. "Must see the new data" means it observes this write or a later one, not necessarily this write's data. The kata extension B and debugging row 6 should say so (A6.4 is about observation, not exclusivity).
