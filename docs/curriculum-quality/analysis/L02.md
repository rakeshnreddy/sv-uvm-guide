**Expert: absent** (no `## Push Further`; the corner cases and interview answers are recall-level and revealed immediately). Add these `### Expert:` items, all with verified clauses:
1. **Driver rules at bit level, port kinds, implicit nets.**
   - The multiple-driver rule applies per longest static prefix, so different bits or elements may each have one continuous driver (§6.5, §11.5.3).
   - `always_comb`/`always_latch`/`always_ff` own their left-hand sides (§9.2.2.2, §9.2.2.3, §9.2.2.4). `uwire` enforces one driver (§6.6.2).
   - `input logic a` is a net, `output logic y` is a variable, `inout` cannot be `var` (§23.2.2.3).
   - `logic y = a & b;` is a one-time initialization while `wire y = a & b;` is continuous (§10.5, §10.3.1).
   - A typo creates an implicit 1-bit net; `` `default_nettype none `` makes it an error (§6.10, §22.8).
2. **Strength and resolution corner cases.**
   - The stronger driver dominates; values fight only at equal strength (§28.12.1).
   - wand/wor truth tables (§6.6.3, Tables 6-3, 6-4).
   - tri0/tri1 read 0/1 at pull strength when undriven (§6.6.5); supply nets (§6.6.6).
   - trireg capacitive state (§6.6.4). Move the existing trireg Q&A here.
3. **Literal and expression-size corner cases.**
   - Unsized literals are at least 32 bits (§5.7.1, Table 11-21).
   - Unsized x/z literals extend to the expression size, but a sized `4'bx` assigned to 16 bits becomes `16'h000x`, because unsigned operands zero-extend (§5.7.1, §11.8.2).
   - In `sig == 1'bx`, the smaller operand is zero-extended (§11.4.5), so the result can be a definite 0.
   - `'1` is 1 bit in a self-determined context (§5.7.1). Unsized constants are illegal in `{}` (§11.4.12).
   - Part-selects and concatenations are unsigned (§11.8.1). `>>>` fills with the sign only when the result type is signed (§11.4.10).
   - A signed resize with an x sign bit fills x (§11.8.4). Real-to-integer conversion rounds (§6.12.1).
4. **X-propagation from RTL to gate level.**
   - LRM if/case optimism vs `?:` (§12.4, §12.5.1, §11.4.11, Table 11-20).
   - Simulator X-propagation modes and gate-level X-pessimism (spine gap G29). Both are tool-dependent: label them, give no vendor switch without a tool name.
   - `$isunknown` and `$countbits(e,'x,'z)` (§20.9) in assertions, linked to I-SV-4A.
5. **2-state vs 4-state at scale.**
   - The LRM says 2-state types "can simulate faster, take less memory" (§6.11.2); the speed-up is tool-dependent.
   - Mixed 2/4-state operands evaluate as 4-state (§11.3.4).
   - Automatic coverage bins ignore sampled values with x/z (§19.5.3), so an x on a monitored field does not show up in coverage. Link I-SV-3A.
   - The team policy that follows from these rules.
6. **Interview angles** (attempt-first, `InterviewQuestionPlayground`), staff level:
   - "Your scoreboard never fails although the DUT drives x after reset: find two causes in the monitor and the checker."
   - "Is `assign v[0]=a; assign v[1]=b;` on `logic [1:0] v` legal?"
   - "`input logic` vs `output logic`: net or variable, and why does it matter?"
   - "What does `w[15:8]` select on `logic [3:0][7:0] w`?"
   - "`logic y = a & b;` at module scope: what happens when `a` changes?"
   - "When would you use a packed union for a protocol header?" (sub-lesson)
