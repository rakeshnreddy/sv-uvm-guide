| L24-3B-01 | S1 | Accuracy (code) | `interrupt-handling.mdx:42` (prose `:111`, `:125`) | `@(vif.mon_cb iff vif.mon_cb.irq);` | The `iff` condition is evaluated at every clocking event, so while a level interrupt stays high the loop publishes once per clock. The page clears interrupts by register write (`:96-99`), so `irq` stays high for many cycles.
