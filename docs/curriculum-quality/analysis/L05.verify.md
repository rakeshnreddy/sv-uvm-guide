   - `static int loop2 = 0` prints 1 to 9.

   Place it with the index pitfall box.
2. **No picture for format specifiers.** The concept table marks the picture as missing, but Visual coverage has no proposal. Add a traced "call → printed text" table built from the compiled example:
   - `%d` vs `%0d` padding and `%h` leading zeros (the §21.2.1.2 examples);

   - `%m`;
   - `%t` vs `%0t`.
3. **`$monitor` prints a first line** at the end of the time step in which it is called (§20.3.1 example output). This is core to the prediction objective.
4. **`%t` details (practitioner):**
   - the default minimum field width is 20;
   - the default units come from the smallest precision of every compiled `` `timescale `` (Table 20-3);
   - so a file compiled with a 1ps library prints in ps.
5. **`ref` corner cases (practitioner and expert):**
   - Actual and formal must be equivalent types, and "No casting shall be permitted" (§13.5.2). For example, passing `logic [7:0]` to `ref byte` is a compile error.
   - `ref input` is illegal (the §13.5.2 example).
   - Inside `fork…join_any` or `fork…join_none`, a `ref` formal may be referenced only in a fork-local initializer unless it is `ref static` (§9.3.2). This is the classic forked-driver or monitor bug.
   - Whether `ref static` is new in 1800-2023 is unverified here. Label its tool support as tool-dependent.
6. **Tasks (expert).** A `return` inside a fork-join block is illegal (the §9.3.2 `wait_20` example, `fork #20; return; join_none`).
7. **Functions (expert):**
   - §13.4 rule c) lets a function kill, suspend or resume another process, or kill the current one.
   - §13.4.4 allows a function that schedules work only when the calling thread comes from `initial`, `always` or a fork. The LRM marks `bit y = watch_for_zero(stack);` as illegal.
   - §13.4: a function with `output`, `inout` or `ref` arguments cannot be called in an event expression, in a procedural continuous assignment, or outside a procedural statement. `const ref` is allowed.
8. **Argument binding (practitioner):**
   - defaults apply only to singular arguments;
   - empty placeholders, as in `read(, 5)`;
   - "all the positional arguments shall come before the named arguments", so `fun(.s("yes"), 2)` is illegal (§13.5.3, §13.5.4).
9. **Severity (expert):**
   - Elaboration severity tasks (§20.10.1) are called outside procedural code, for example in a generate `if` that rejects bad parameters. At elaboration, `$error` lets elaboration continue but "simulation shall not be started". The card's "`$error` continues" therefore needs "at run time".
   - §20.10: an assertion with no `else` calls `$error` by default (a forward link to SVA).
10. **Ending and dumping (practitioner):**
    - `final` allows only statements that are legal in a function (§9.2.3), so a PASS/FAIL summary in `final` cannot wait.
    - All `$dumpvars` calls "shall be at the same simulation time" (§21.7.1.2). This matters when a `+DUMP` gate fires late.
