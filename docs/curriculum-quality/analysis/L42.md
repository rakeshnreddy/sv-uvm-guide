**Expert:** absent. `## Push Further: Triage Playbook` is practitioner content and there are no `### Expert:` items. Add the following, sources verified:

1. **Catcher corner cases.**
   - A severity change without `set_action()` resets the action to the new severity's default (uvm-core `uvm_report_catcher.svh:600-610`).
   - CAUGHT stops later catchers (§6.6 overview; §6.5.1.2.14 a).
   - `issue()` emits a CAUGHT message (§6.6.6.6).
   - Messages issued from inside a catcher bypass catchers (§6.6.6).
   - The "Number of demoted/caught …" summary prints at `UVM_LOW`, so `+UVM_VERBOSITY=UVM_NONE` hides it (`uvm_report_catcher.svh:711-727`, printed with `UVM_LOW` at `:720`, `:727`).
   - `uvm_report_catcher::debug_report_catcher(1)` (DO_NOT_CATCH) and `print_catcher()` audit catchers (uvm-core impl., `@uvm-accellera`, `:342`, `:381`).
   - A type-wide (`null`) catcher differs from a per-object one (§6.6 overview; D.4.3 `uvm_report_cb`).
   - Catchers do see `UVM_NO_ACTION` messages issued through the `uvm_report_*` functions, but never those from the macros, which pre-check the action (`uvm_message_defines.svh:130-135`; `uvm_report_object.svh:171-178`).
2. **When command-line report settings apply.**
   - `+uvm_set_*` is applied in each component's constructor (`uvm_component.svh:1803` → `m_set_cl_msg_args`), so a later `set_report_*` call in code wins.
   - Sequences report through their sequencer's report object (`uvm_sequence_item.svh:386-395`, §14.1.3), so target the sequencer path.
   - No ID wildcards, only `_ALL_` (G.2.3).
   - The first `+UVM_TESTNAME`/`+UVM_VERBOSITY` wins, with a warning (G.2.1, G.2.2).
   - `+UVM_MAX_QUIT_COUNT=N,NO` locks the count (G.2.6).
   - `+UVM_TIMEOUT` is read with `%d` (`uvm_root.svh:916`), so `10ms` becomes 10 units of uvm_pkg's time unit. `uvm_pkg` declares no `timeunit` and the default unit is tool-specific (IEEE 1800-2023 §22.7), so the setting is tool-dependent.
3. **Random stability in UVM regressions.**
   - SV thread and object stability (IEEE 1800-2023 §18.14.1).
   - UVM reseeds components in `new()` and sequences and items in `set_item_context()` from type name plus full name (§5.3.3.3, §14.1.2.2; uvm-core `uvm_component.svh:1780`, `uvm_sequence_item.svh:143`, `uvm_object.svh:816`).
   - Report messages, `config_db` set/get and recording preserve the caller's random state (§6.2.2.2; uvm-core `uvm_config_db_implementation.svh:349,422` (set) and `uvm_resource_pool.svh:558-570` (the lookup that get uses)).
   - What does shift a seed: new `new`/fork/randomize calls in a thread; renamed components or sequences; a changed order of same-type items started in one sequence (the seed uses a per-name count, `uvm_misc.svh:182-189`); debug code such as `sprint()` (`uvm_printer.svh:1144-1150` creates elements with `new`); a different tool version or compile option.
   - `set_uvm_seeding(0)` (§5.3.3.2) turns name-based reseeding off.
4. **Timeouts, heartbeats and hangs that never time out.**
   - `set_timeout` is *absolute* simulation time (F.7.3.3); the uvm-core default is 9200 s (`uvm_global_defines.svh:85`).
   - The watchdog is a `#` delay (`uvm_macros.svh:76`, `uvm_phase_hopper.svh:561`), so a zero-delay loop that never advances time never raises `PH_TIMEOUT`.
   - With `+UVM_PHASE_TRACE`, the timeout also prints which phases have outstanding objections (`uvm_phase_hopper.svh:572-589`).
   - `uvm_heartbeat` detects a silent component per window (§10.6), long before the global timeout.
5. **Machine-readable logs at scale.**
   - A custom report server overriding `compose_report_message` (§6.5.1.2.15), installed with `set_server` (§6.5.1.2.19).
   - Per-ID log files (§6.3.6.2).
   - `UVM_RM_RECORD`, which sends messages to the recorder (F.2.2.2), and structured `uvm_info_begin`/`uvm_message_add_*` (uvm-core impl., `uvm_message_defines.svh:330,523`).
   - Guard expensive message bodies with `uvm_report_enabled` (§6.3.3.2).
6. **Waveform and recording budgets.**
   - Windowed VCD (§21.7.1.2–21.7.1.6); a rerun window derived from the failing log.
   - Dump control cannot live in a package, because package items cannot hold hierarchical references (§26.2); it goes in `tb_top`.
   - Per-agent recording with `set_recording_enabled_hier` (D.2.3).
   - FSDB, WLF and SHM, and ring buffers, labelled tool-dependent.
7. **Staff-level interview angles**, attempt-first, using bank questions `debug-staff-regression-triage`, `uvm-staff-debug-hanging-sim` and `debug-waveform-protocol-hang`, plus new ones:
   - "a regression is green but a bug escaped";
   - "my seed stopped reproducing after I added a print".
