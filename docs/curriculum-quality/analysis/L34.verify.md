## Completeness and depth gaps the analyst missed

1. **X-safety across the environment (V02, -10, -16).**
   - The analyst covers the 2-state monitor fields only.
   - Practitioner layer: X checks in the checker, and why an X antecedent makes a property pass vacuously.
   - Make It Work checklist item: "X checks on HTRANS, HREADY and HRESP".
2. **`$sampled` in action blocks (V01).** Add this debugging technique to the debug walkthrough and to the expert item on assertions in a UVM regression.
3. **Slave-port checks need data-phase ownership (refines Expert 1).**
   - Slave obligations checked on one slave's HREADYOUT/HRESP must apply only while that slave owns the data phase: HSELx, sampled at the accepting edge with HREADY high and NONSEQ/SEQ, registered.
   - Without that gate, the checks fire on unselected slaves.
   - Sources: IHI0033B.b §4.2, §2.4 Note.
4. **Responder timing (stimulus must-cover).**
   - A reactive responder must drive HREADYOUT/HRESP in the same time step as the accepting edge, with HREADYOUT high by default.
   - Without this, it can never put a wait state or an ERROR in the first data-phase cycle. See the Visual row 8 adjustment.
5. **Formal reuse versus UVM reporting.** Expert 3 (assume-guarantee) and the -06 fix (`` `uvm_error ``) conflict for one checker module. Teach a reporting macro chosen by a define (tool-dependent).
6. **Reset in the coverage plan.**
   - The proposed vplan has no reset item, although reset is a must-cover.
   - Add `cover property` items for reset asserted while a transfer is pending, and for the first transfer after reset.
7. **Two core concepts still have no planned picture.**
   - **Transaction item, beat versus burst:** a traced table of an INCR4 read with one BUSY and one wait. It yields four beat items (`beat_index` 0–3; BUSY is not a beat) and one burst item.
   - **Transaction-boundary finder:** a traced table with back-to-back NONSEQ singles and a waited NONSEQ, counting accepted beats. This is the fix for -17 shown as a picture.
8. **Completeness-table spot-check.**
   - Objective 2 should read "partial", not "yes, with gaps": it lacks X checks, HWDATA hold, the HSIZE bound and beat counting, and it reports with `$error`.
   - The other rows hold: I confirmed the missing stimulus side, the partial reset coverage and the absent misconception 3 by searching the page.
