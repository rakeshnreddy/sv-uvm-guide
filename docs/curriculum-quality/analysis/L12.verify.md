## Completeness and depth gaps the analyst missed

1. **Shallow copies carry the randomization state (expert; randomization-methods and controlling-randomization).**
   - In IEEE 1800-2023, `p2 = new p1;` copies the RNG state, the `constraint_mode` and `rand_mode` status, and the `randc` cyclic state (§8.12).
   - So the copy repeats the original's next values unless it is reseeded with `srandom()`. Teach this beside "what changes a seed's results".
   - Whether UVM `copy()` or `clone()` carries this state is unverified; check uvm-core before teaching it.
