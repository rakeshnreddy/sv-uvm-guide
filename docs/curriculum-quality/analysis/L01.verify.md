2. **F1A, concept table.** Mark Respin types → Pitfalls as **no**, not partial. The page names no respin pitfall, and F1A:16 states misconception 1 (L01-F1A-V01).

   - architect: spec;
   - design: RTL;
   - DV: vplan, bench, regression;
   - formal: proofs;
   - emulation: software bring-up;
   - DV lead: sign-off.
4. **F1B, core: the X-blind compare.** The plan's "three ways a check never fails" (L01.md:438, 493, 587) leaves it out. Yet the Make It Work checklist requires "I compare with `!==`" (L01.md:586). Teach it in Build Your Mental Model as the fourth way: in `if (count != expected)`, an X gives 1'bx (§11.4.5), and an `if` on x does not run its first statement (§12.4). Today it appears only in the debug challenge (L01.md:669).
