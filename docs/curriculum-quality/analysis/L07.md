  - Add the real layout: one package per agent, which `` `include ``s its class files (I-SV-1 preview).
- **Expert: absent.** Push Further (:118-120) has two prompts. Add these `### Expert:` items; all clauses were verified this session:
  1. **Name-resolution corner cases.**
     - A wildcard candidate is imported only by a reference.
     - Two wildcard providers are an error only when a reference binds to the name.
     - A local declaration after a binding reference is illegal (§26.3 Example 1).
     - An explicit import is illegal if the name is declared locally or explicitly imported from another package (§26.3).
     - Outer-scope search order (§26.3 Examples 2–4) and Table 26-1 (§26.5).
     - `.*` "does not create a sufficient reference for a wildcard import" (§23.3.2.4).
     - "It shall be illegal to have an import statement directly within a class scope" (§26.3).
  2. **Type identity.**
     - "Each instance with a user-defined type declared inside the instance creates a unique type" (§6.22).
     - A typedef matches only within its own scope (§6.22.1 d), so the same file `` `include ``d into two packages gives two types.
     - Enums and classes then refuse assignment (§6.19.3, §6.22.4, §6.22.5: "Class handles … are type incompatible with all other types").
     - Packed structs are merely *equivalent* (§6.22.2 c), so they connect silently.
  3. **Compilation units.**
     - The compilation-unit scope is local to a compilation unit. Which files form one is tool-specific: single-unit and multi-unit modes are both required (§3.12.1).
     - `$unit` items cannot be referenced from another unit.
     - Directives do not cross separately compiled units.
     - A package "shall not refer to items defined in the compilation-unit scope" (§26.2).
     - Compile-before-use (§26.3) makes two packages that import each other impossible. This is a logical consequence of the rule; label it as such.
  4. **`export` and umbrella packages.**
     - Imports into a package are not visible to its importers (§26.6).
     - `export pkg::*` exports only names actually imported, that is, referenced.
     - `export *::*`.
     - Multiple export paths to one declaration do not conflict.
     - `export p1::x` counts as a reference, so a later local `x` is an error (p6 example).
  5. **The `std` package.**
     - It is implicitly wildcard-imported into every compilation unit.
     - User declarations hide its names.
     - `std::` reaches them unambiguously (§26.7).
     - Contents: semaphore, mailbox, randomize, process and the 2023 weak-reference class (Annex G.2).
  6. **Parameter and port corner cases.**
     - With a parameter port list, body `parameter`s are local (§23.10).
     - Ordered and named overrides cannot be mixed (§23.10.2).
     - `defparam` beats an instance override (§23.10). It "might be removed from future versions" (§6.20 NOTE, Annex C.4.1).
     - In a package, `parameter` = `localparam` (§6.20.4).
     - `input var logic` declares a single-driver variable input (§23.2.2.3, mh6).
     - Port coercion of a driven input to inout, with a warning (§23.3.3.1).
     - Tool-dependent: under `` `default_nettype none `` an `input logic` port is "a net of default net type" (§23.2.2.3) while §22.8 demands that every net be declared explicitly. Write `input wire logic` or `input var logic` to be portable, and label tool behaviour as tool-dependent.
  7. **Methodology at scale** (label tool-dependent where so).
     - Package layering: shared types → per-agent packages → env → test.
     - One class per file, `` `include ``d into exactly one package.
     - Recompile fan-out when a widely imported package changes.
     - Link the bank item `sv-staff-methodology-reuse`.
  8. **Interview angles**, attempt-first:
     - "Two packages define `data_t`; you wildcard-import both and never use it. Error?"
     - "`uvm_config_db#(cfg)::get` fails although `set` looks identical. Why?" (two packages include `cfg.svh`; UVM preview)
     - "What does `.*` connect, and when is it dangerous?"
     - "`input logic` vs `input var logic`?"

1. `### Worked example: a counter bench with a shared package`. Code (checked by inspection against the clauses cited in its comments):

   ```systemverilog
   // compile
   // Compile order: cnt_pkg, tb_pkg, counter, tb_top. A package is compiled
   // before any scope that refers to it (IEEE 1800-2023 §26.3).
   `timescale 1ns/1ps

   package cnt_pkg;                         // shared by the design and the bench
     typedef enum logic [1:0] {OP_HOLD, OP_INC, OP_LOAD} op_e;
   endpackage

   package tb_pkg;                          // bench only
     import cnt_pkg::*;

     typedef struct packed {
       op_e        op;
       logic [7:0] din;
     } cmd_t;

     // Reference model: the value q must hold one clock after cmd c is applied.
     function automatic logic [7:0] predict(input logic [7:0] q, input cmd_t c);
       case (c.op)
         OP_INC:  return q + 8'd1;
         OP_LOAD: return c.din;
         default: return q;
       endcase
     endfunction
   endpackage

   module counter
     import cnt_pkg::*;                     // header import: op_e usable in ports (§26.4)
     #(parameter int WIDTH = 4)
     (
       input  logic             clk,        // input, no kind given: a net (§23.2.2.3)
       input  logic             rst_n,
       input  op_e              op,
       input  logic [WIDTH-1:0] din,
       output logic [WIDTH-1:0] q           // output with a data type: a variable
     );
     always_ff @(posedge clk or negedge rst_n)
       if (!rst_n)             q <= '0;
       else if (op == OP_INC)  q <= q + 1'b1;
       else if (op == OP_LOAD) q <= din;
   endmodule

   module tb_top;
     import cnt_pkg::*;                     // tb_pkg does not export cnt_pkg (§26.6)
     import tb_pkg::*;

     logic       clk = 1'b0;
     logic       rst_n;
     op_e        op;
     logic [7:0] din;
     logic [7:0] q;
     int         n_pass = 0, n_fail = 0;

     always #5 clk = ~clk;

     // Named override; .* connects clk, rst_n, op, din and q because names and
     // types match (§23.3.2.4). Equivalent: .clk(clk), … or .clk, .rst_n, …
     counter #(.WIDTH(8)) dut (.*);

     // Drive on the falling edge, half a cycle before the DUT samples, so the
     // drive cannot race the DUT's flop (F3C). F4C replaces this with a clocking block.
     task automatic apply(input op_e o, input logic [7:0] d);
       cmd_t       c;
       logic [7:0] exp_q;
       c     = '{op: o, din: d};
       exp_q = predict(q, c);
       op    = o;
       din   = d;
       @(negedge clk);                      // the rising edge in between updated q
       if (q !== exp_q) begin
         n_fail++;
         $error("%s din=%0d: q=%0d, expected %0d", o.name(), d, q, exp_q);
       end else n_pass++;
     endtask

     initial begin
       rst_n = 1'b0;
       op    = OP_HOLD;
       din   = '0;
       repeat (2) @(negedge clk);
       rst_n = 1'b1;
       apply(OP_LOAD, 8'd254);
       apply(OP_INC,  8'd0);
       apply(OP_INC,  8'd0);                // 255 + 1 wraps to 0 in 8 bits
       apply(OP_HOLD, 8'd7);
       apply(OP_INC,  8'd0);
       $display("PASS=%0d FAIL=%0d", n_pass, n_fail);
       $finish;
     end
   endmodule
   ```

   **Expected output** (hand-traced; the author must run it, then name the simulator and version or label it illustrative): `PASS=5 FAIL=0` at t=70 ns, followed by the tool's `$finish` line.
   - **Break it:** change the DUT's `q + 1'b1` to `q + 2'd2` and get `FAIL=3` with `$error` lines. Move `tb_top.sv` before `cnt_pkg.sv` in the compile command and see the "unknown package or type" class of error. Delete `import cnt_pkg::*;` from `tb_top` and `op_e` is undeclared, because imports are not transitive.
   - A **Run it** box: compile the packages first, then modules (tool-neutral).

   ```systemverilog
   // compile
   `timescale 1ns/1ps

   // The Modport Explorer's interface, plus idle(), write() and modport api.
   interface simple_bus_if (input logic clk);
     logic [31:0] addr;
     logic [31:0] data;
     logic        rw;      // 1 = read, 0 = write
     logic        valid;
     logic        ready;

     clocking cb @(posedge clk);               // timing: F4C
       default input #1step output #0;
       output addr, data, rw, valid;
       input  ready;
     endclocking

     modport master  (input clk, ready, output addr, data, rw, valid);
     modport slave   (input clk, addr, data, rw, valid, output ready);
     modport monitor (input clk, addr, data, rw, valid, ready);
     modport drv     (clocking cb);
     modport api     (import idle, write);     // callers may only call these (§25.7)

     task automatic idle();                    // hold the bus idle while reset is asserted
       cb.valid <= 1'b0;
     endtask

     // VALID rises without looking at READY and stays high until READY is
     // sampled high, so this handshake cannot deadlock.
     task automatic write(input logic [31:0] a, input logic [31:0] d);
       @(cb);                                  // synchronize first (F4C)
       cb.addr  <= a;
       cb.data  <= d;
       cb.rw    <= 1'b0;
       cb.valid <= 1'b1;
       do @(cb); while (cb.ready !== 1'b1);    // an unknown READY is not a handshake
       cb.valid <= 1'b0;
     endtask
   endinterface

   module slave_dut (simple_bus_if.slave bus, input logic rst_n);
     // READY may come before VALID; this slave toggles it every cycle after reset.
     always_ff @(posedge bus.clk or negedge rst_n)
       if (!rst_n) bus.ready <= 1'b0;
       else        bus.ready <= ~bus.ready;
   endmodule

   module bus_monitor (simple_bus_if.monitor bus);
     int unsigned n = 0;
     // Reading at the edge is deterministic here: every writer uses <= or the
     // clocking block (F3C). F4C replaces this with a monitor clocking block.
     always @(posedge bus.clk)
       if (bus.valid === 1'b1 && bus.ready === 1'b1) begin
         n++;
         $display("t=%0d: write addr=%h data=%h", $time, bus.addr, bus.data);
       end
   endmodule

   class tb_driver;                            // class syntax: preview of I-SV-1
     virtual simple_bus_if.api vif;            // a handle; null until assigned (§25.9)
     function new(virtual simple_bus_if.api vif);
       this.vif = vif;
     endfunction
     task run();
       vif.write(32'h0000_1000, 32'hA5A5_0001);
       vif.write(32'h0000_1004, 32'hA5A5_0002);
     endtask
   endclass

   module tb_top;
     logic clk   = 1'b0;
     logic rst_n = 1'b0;
     always #5 clk = ~clk;

     simple_bus_if bus_if (.clk);              // .name connection to the interface port
     slave_dut     dut    (.bus(bus_if.slave), .rst_n);
     bus_monitor   mon    (.bus(bus_if.monitor));

     tb_driver tb_drv;

     initial begin
       tb_drv = new(bus_if);                   // instance -> modport-typed vif (§25.9)
       tb_drv.vif.idle();
       repeat (2) @(negedge clk);
       rst_n = 1'b1;                           // falling edge: cannot race the flops
       @(negedge clk);                         // one idle cycle after reset
       tb_drv.run();
       repeat (2) @(negedge clk);
       $display("transfers=%0d", mon.n);       // a hierarchical name (F4A)
       $finish;
     end
   endmodule
   ```
