## Completeness and depth gaps the analyst missed

**E-RISCV-1**

1. **What riscv-dv's compare actually checks** (practitioner and expert). See V05.
   - `instr_trace_compare.py` compares GPR write values in order, skipping non-writing instructions. Leftover state-changing entries are counted as mismatches (the analyst's claim is confirmed).
   - Stores are never compared directly.
   - `run.py` steps are `gen, gcc_compile, iss_sim, iss_cmp`; `iss_cmp` compares two ISSes.
   - The RTL simulation and the RTL-vs-ISS compare live in the core's own end-to-end flow (`end_to_end_simulation.rst` points to the Ibex Makefile).

   Teach this so learners do not assume their RTL is checked store by store.
2. **Multi-retire ordering** (expert). RVFI has `NRET` channels, and retirement "may be … reordered … as long as causality is preserved" (`rvfi.rst:41-45`). riscv-dv's compare has an unimplemented "out of order comparison" TODO for cores that commit several instructions per cycle (`instr_trace_compare.py:135-150`). Superscalar cores need per-cycle reordering, or a final-GPR compare, in the robust compare. This expert item is missing from the eight.
3. **ISS configuration alignment, shown concretely.** riscv-dv's Spike command is `spike --log-commits --isa=<variant> --priv=<priv> --misaligned -l <elf>` (`yaml/iss.yaml:18`). The analyst's how-to step 2 ("Align the ISS configuration") should name these flags, since `--misaligned` and `--priv` are the usual sources of false mismatches.
4. **`+boot_mode`, `+no_wfi` and `+no_ecall` as the generator side of "how does a test end".** The analyst's flow covers TEST_RESULT. Name the generator options that interact with it (`no_wfi` default 1; `ecall` handler → `test_done` → `write_tohost`; `riscv_asm_program_gen.sv:85-134, 345-346`).

5. **Reviewing LLM-generated UVM sequences**, plus "invented API or plusarg" in the failure catalogue (V07). The page has a sequence-skeleton section, and the spine objective names sequences.
6. **A Concept completeness row for "LLM drafting of sequences" is missing.** The analyst's table covers SVA only.
7. **The `hole` stimulus preset** (`coverage-model.ts:1640`) could serve the "what ML cannot close" picture directly, alongside `mode="closure"`. The author should check which preset shows a probability-0 bin.
