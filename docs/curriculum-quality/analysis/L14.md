1. **Type coverage corner cases.**
   - Instances are averaged by their `option.weight`, or merged as a union of bins matched by name. Instances with different bin sets come from covergroup arguments (§19.11.3, including the LRM's `gt`/`gv1`/`gv2` example: 66.6667, 100.0 and 50.0).
   - `option.get_inst_coverage` (Table 19-1).
   - `per_instance` and `get_inst_coverage` can be set only in the definition (§19.7).
   - Type options other than `strobe` and `real_interval` can be assigned procedurally (§19.7.1).
2. **Zero-denominator and zero-weight rules** (§19.11, §19.11.1, §19.11.2):
   - an item whose bins are all ignored drops out of the group number, yet its own `get_coverage()` returns 0.0 (or 100.0 if its weight is 0);
   - `$get_coverage()` returns 100.0 when no covergroup instance exists.
3. **`(covered, total)` on a covergroup** is a sum of bin counts, not the numerator and denominator of the percentage (§19.8). Dashboards that divide them are wrong.
4. **Sampling a covergroup from an assertion:** an overridden `sample()` called from a property, with local variables (§19.8.1), versus `cover property` (I-SV-4A).
5. **Reusable coverage models:**
   - `covergroup extends` in a derived class (§19.4.1);
   - the embedded covergroup's anonymous type, so static calls go through an instance (§19.4);
   - covergroup arguments that give each instance different bins, and the effect on the union (§19.11.3).
6. **What `dist` steering guarantees:** probabilities hold only "absent any other constraints". When other constraints make the weights unsatisfiable, implementations are "only required to satisfy the constraints" (§18.5.3). Measure the effect; do not assume it.
7. **Exclusion and waiver governance (tool-dependent):**
   - in-model vs tool exclusions, the audit trail, re-review on spec change;
   - formal reachability as evidence (link E-INT-1);
   - UCIS 1.0 (Accellera, 2012) as the interoperability API.
8. **Closure at regression scale (tool-dependent):**
   - merging, ranking tests by unique contribution, plateau-based stops;
   - `$set_coverage_db_name` and `$load_coverage_db` (§19.9), whose tool support varies;
   - when to switch from random to directed tests, formal or PSS.
9. **Performance and scale:**
   - cross explosion: bins multiply across the crossed coverpoints (§19.6);
   - `per_instance` database size;
   - query cost: poll every N transactions;
   - `option.cross_num_print_missing` for reports (Table 19-1);
   - `type_option.strobe` (Table 19-3);
   - coverage-off switches in long regressions. Label costs as tool-dependent.
10. **Staff-level interview angles** (attempt-first), listed in the outline.

| Symptom | Likely cause | Fix |
|---|---|---|
